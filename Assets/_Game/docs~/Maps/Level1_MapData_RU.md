# Уровень 1: Глава 1: Пробуждение

**Локация:** Обсидиановое Святилище (Гробница Владыки)
**Размер сетки:** 15 (Ширина) x 9 (Высота)

## 1. Атмосфера и освещение
*   **Атмосфера:** Древнее место упокоения Владыки Демонов. Холодно, угнетающе, но пульсирует пробуждающейся темной магией.
*   **Освещение (Глобальное):** Обесцвеченные, кромешно-черные тени, пронзаемые глубоким, светящимся окружающим фиолетовым светом.
*   **Освещение (Локальное/Точечное):** Парящие искры огненно-оранжевого и проклятого фиолетового цвета медленно дрейфуют в воздухе.
*   **Туман:** Густой, плотный, клубящийся **фиолетовый туман**, который полностью поглощает участки за пределами главной тропы, клубясь вокруг древних гробниц.

## 2. Спецификации тайлов (1:1 Unity Кубы)
*   **Проходимые тайлы пути (Одиночная линия):**
    *   **Текстура/Материал:** Единственная, узкая извилистая линия потрескавшихся, пыльных каменных плит.
    *   **Декорации:** Разбросанные кости, древняя пыль.
*   **Непроходимые тайлы (Препятствия и пустота):**
    *   **Текстура/Материал:** Массивные, возвышающиеся стопки древних каменных гробов и саркофагов.
    *   **Декорации:** Гробы служат стенами уровня, выступая из густого фиолетового тумана.

## 3. Планировка карты
*   **Точка появления:** (14, 2)
*   **Точка выхода:** (5, 4)
*   **Структура:** Единственная, узкая, извилистая тропинка. Враги вынуждены идти по этому единственному клаустрофобному коридору.

---

## 4. Промпты для ИИ-генерации изображений

> **Промпт для вида сверху (Top-Down):** Вид сверху, строго ортогональная проекция уровня 3D-карты для игры в жанре tower defense, размером 15 на 9 тайлов. Сеттинг — темная фэнтезийная готическая гробница. Построено из кубических блоков 1:1. В центре проходит единственная узкая извилистая тропа шириной в один тайл из пыльных потрескавшихся каменных плит. Все непроходимые тайлы — это возвышающиеся стопки древних каменных гробов и саркофагов, служащие стенами и сильно окутанные густым, непрозрачным, светящимся фиолетовым туманом, стелющимся по земле. В воздухе парят светящиеся искры. Шедевр, высокодетализированные текстуры, стиль темного фэнтези аниме, кромешно-черные тени, без персонажей, без интерфейса.

> **Промпт для изометрического тайла (Isometric):** Изометрический вид одиночного 3D квадратного тайла пола для игры в жанре темного фэнтези. Потертая, потрескавшаяся серая каменная плита. Тайл частично скрыт густым, ползущим, светящимся фиолетовым туманом и парящими магическими искрами. Глубокие черные тени. Шедевр, высокодетализированная текстура, бесшовная, на темном фоне.

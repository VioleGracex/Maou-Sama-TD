# Gacha Character Portrait Prompts (1:1 Ratio)

This document provides standardized prompts for generating 1:1 aspect ratio character portraits for the Gacha system, categorized by character class.

## Core Visual Style (Global Tags)
**Base Style**: `fate ufotable anime style, high fantasy, dark atmosphere, cinematic lighting, sharp focus, vibrant but deep colors, intricate details, masterwork quality, 8k resolution`
**Framing**: `close-up portrait, head and shoulders, centered, looking at viewer, 1:1 aspect ratio`
**Background**: `abstract dark magical background, swirling mana, subtle particles, no clutter`

---

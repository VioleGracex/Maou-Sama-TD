# Story Splash Art Prompts

This folder contains markdown files organized by Level or Story Act, containing specific prompts for generating splash arts used in dialogues, cutscenes, and loading screens.

## File Organization
- `L1_Awakening_Splashes.md`: Level 1 story prompts.
- `L2_Lust_Reclamation_Splashes.md`: Level 2 story prompts (Lilith's arrival).
- (Follow this naming convention for new story arcs)

## Image Types
- **Waist-up**: Best for dialogue boxes where character expression is key.
- **Full Body**: Best for major story beats, introductions, or victory screens.
- **Environmental**: Used for background context or showing the world's reaction to the Maou.

## Generation Guidelines
1.  **Use the Foundation**: Always copy the Style Foundation (Positive/Negative base) from the top of the file.
2.  **Character Consistency**: Refer to the character documentation in `Assets/_Game/docs~/characters/` to ensure specific traits (horns, hair color, eyes) are included.
3.  **Naming Characters**: Use the character's name in the prompt (e.g., `1girl, Tina`) to help the AI model recognize the intended design if trained, or to reinforce the description.
4.  **Composition**: Specify `waist-up`, `bust shot`, or `full body` clearly.
